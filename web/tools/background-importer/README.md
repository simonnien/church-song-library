# 背景影片匯入工具（可選本機 AI、免 Google 授權）

雙擊本資料夾的 `start.cmd`。這台電腦已具備 Python、imageio-ffmpeg、Node 與網站依賴。
日常操作不使用 Codex token。可選用本機 AI 建議名稱；轉檔與辨識消耗本機資源，上傳及驗證會使用網路與 Drive 空間，部署仍受 Cloudflare 額度限制。

## 日常 SOP

1. 選擇影片，輸入名稱或點「本機 AI 建議名稱」，選 16:9、32:9 或兩種。工具會自動避開現有資料庫的同名。
2. 按「產生影片與縮圖」。原片不會被改動。輸出為 H.264、30fps、無聲、1080 高度，畫面居中裁切；兩種比例不拉伸。
3. 按各比例「預覽」，確認裁切。自行在播放器開循環播放，觀察至少三輪。
   預設尾接頭淡化約 0.8 秒，不能保證自然無縫，可能出現疊影；原片已無縫時可取消淡化後重新產生。
4. 「開啟產出資料夾」，只把其中 MP4 上傳 Google Drive。請勿上傳原片代替工具輸出。
5. 在 Drive 將每支影片的「一般存取權」設成「知道連結的任何人／檢視者」。不必開放編輯。
6. 將各比例的檔案分享連結分別貼回工具。兩種比例必須是兩個不同檔案。
7. 勾選「已預覽」，按「驗證 Drive 影片並發布正式網站」。工具會重新下載雲端檔，比對長度和 SHA256，確認完整後更新清單、複製縮圖、建置及部署。
8. 看到「發布成功」後重新整理 https://songs.beersheba.cc ，在對應比例選單找影片，匯出一個專案到 FreeShow 實測。

## 中斷及故障

- 工作存在 `web/.sites-runtime/background-importer/` 的個別資料夾；選「開啟之前的工作」，挑該資料夾的 job.json。
- 分享權限不對、Drive 限流或上傳不完整：驗證不通過，不發布；修正後重試。
- 部署授權過期：雙擊「Cloudflare登入.cmd」，在瀏覽器重新授權，再按發布。
- 建置失敗：工具恢復原本影片清單；錯誤顯示在下方。不要反覆改檔，先看錯誤。
- 部署失敗：本機清單保留，再次發布會使用同一批影片，不重複加入。
- 此工具使用目前本機網站版本發布。請勿在其他人正修改或部署網站時同時執行。
- 工具不會自動提交你的其他程式碼到 Git。若需要備份，於網站資料夾開終端：
  `git add lib/background-catalog.json public/background-thumbnails`
  `git commit -m "Add background videos"`
  `git push`
- 不要刪除已上架的 Drive 影片，也不要以不同內容取代同一個 Drive ID；要更新影片請另傳新檔並使用新名稱。

## 測試

執行 `py -3 tools/background-importer/test_importer.py` 驗證雙比例實際轉檔與解碼、縮圖、連結解析、重試不重複加入及不完整下載拒絕。
發布按鈕會影響正式網站，測試不會自動發布示範影片。

## 選用本機 AI 建議名稱

1. 安裝官方 Ollama：https://ollama.com/download/windows
2. 開啟終端執行 `ollama pull gemma3:4b`，模型約 3.4 GB。
3. 保持 Ollama 執行，工具選影片後按「本機 AI 建議名稱」。
4. 工具只把前、中、後三張畫面送到這台電腦的 127.0.0.1，不傳雲端；點建議名稱採用，也可手動修改。
5. 轉檔前自動比對本機網站影片清單，重複名稱自動加 _02、_03。它是名稱防重複，不是判斷影片內容是否相同。

模型可能判斷錯誤，仍請看名稱是否貼切；不需要你人工查重。RTX 3050 Ti 筆電可能使用部分系統記憶體，首次推論較慢。未安裝 AI 不影響其他功能。
