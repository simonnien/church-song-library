# Google Drive 連接設定

資料檔：https://drive.google.com/file/d/YOUR_DRIVE_FILE_ID/view

請先建立自己的 JSON 資料檔，並將 Code.gs 的 YOUR_DRIVE_FILE_ID 替換成檔案 ID。自動連接仍須完成以下設定；完成前，網站繼續使用網站雲端資料庫。桌面 EXE 使用本機 SQLite，不會自動同步。

## 一次性設定

1. 開啟 Apps Script 專案「詩歌書房 Drive 同步」，將 Code.gs 的內容放入程式碼.gs 並儲存。
2. 上方函式選擇 initialize，按執行。使用你自己的 Google 帳戶完成授權。這會設定資料檔 ID，產生網站專用密鑰，並確認能讀取資料檔。
3. 部署 → 新增部署 → 選取類型「網頁應用程式」。執行身分選「我」，誰可以存取選「所有人」。Drive 檔案仍保持私人；程式會檢查每次請求的密鑰。
4. 保留結尾 /exec 的部署網址。專案設定 → 指令碼屬性可以找到 BRIDGE_TOKEN。請勿把密鑰放到聊天、歌詞或公開頁面。
5. 網站伺服器需設定秘密環境變數 DRIVE_BRIDGE_URL（部署網址）及 DRIVE_BRIDGE_TOKEN（密鑰）。切換前再把網站最新歌曲更新到同一個 Drive 資料檔，保留檔案 ID。
6. 重新部署網站，確認顯示「Google Drive 已連結」，測試讀取及儲存。

連接後網站以 Drive 為主要資料來源，每次儲存會檢查版本，並先在「詩歌書房-修改備份」保留備份。讀寫失敗時顯示錯誤，不會寫到另一份資料庫。

公開訪客可以閱讀與匯出；beershebr01 至 beershebr10 為編輯者帳號，登入後才能儲存。Google 授權只負責網站伺服器存取 Drive，與編輯者登入不同。
